# TimeOmni-o1 · MMTR

Project page for **TimeOmni-o1: Bidirectionally Coupling Time Series Foundation Models and LLMs for Multimodal Reasoning and Forecasting**
(Ziyang Zhang, Shenyi Li, Wen Wu, Chao Zhang). Code: https://github.com/windowso/TimeOmni-o1

The page (`index.html`) collects, from the paper and its appendix, the abstract, the model figures
with the method text, the MMTR dataset description, annotated samples and case studies.

The site is static: open `index.html` directly, or view it through GitHub Pages
(the workflow in `.github/workflows/pages.yml` deploys the repository root on every push to `main`).
